# Exercism Rust Track Solutions

This repository contains my solutions to the [Exercism Rust Track](https://exercism.org/tracks/rust) exercises. Each directory represents a different exercise from the track.

## Structure

Each exercise is in its own directory and contains:
- Source code in `src/`
- Tests in `tests/`
- Exercise documentation in `README.md`
- Cargo configuration in `Cargo.toml`

## Running Tests

To run tests for any exercise:

```bash
cd exercise-name
cargo test
```
